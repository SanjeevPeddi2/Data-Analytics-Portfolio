# Data Analytics Portfolio

## About Me

Welcome to my Data Analytics Portfolio. This repository showcases my assignments and projects using Microsoft Excel, MySQL, Power BI, and Tableau.

My goal is to develop practical skills in data analysis, database querying, data modelling, and dashboard development.

## Skills and Tools

* **Excel:** Power Query, Power Pivot, Data Modelling, Pivot Tables, Pivot Charts, and Slicers.
* **MySQL:** SQL queries, filtering, joins, aggregate functions, subqueries, and window functions.
* **Power BI:** Data Transformation, Data Modelling, DAX, and Interactive Reports.
* **Tableau:** Data Visualization, Filters, Calculated Fields, and Interactive Dashboards.
