# Excel Dashboard Project

## Project Overview

This project demonstrates the development of an interactive dashboard using Microsoft Excel.

## Tools and Features

* Microsoft Excel
* Power Query
* Power Pivot
* Data Modelling
* Pivot Tables
* Pivot Charts
* Slicers

## Project Objectives

* Prepare and transform data using Power Query.
* Organize relationships between data tables using data modelling.
* Analyze information using Pivot Tables.
* Visualize important information using Pivot Charts.
* Explore data through interactive slicers.

## Files Included

* `Excel_Dashboard.xlsx` — Excel dashboard workbook.
* `Dashboard_Screenshot.png` — Dashboard preview.

## How to Use

1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Navigate to the dashboard worksheet.
4. Use the available slicers to explore the data.

Some data connections may require configuration before refreshing.

## Skills Demonstrated

Data Cleaning, Data Transformation, Data Modelling, Data Analysis, and Data Visualization.
