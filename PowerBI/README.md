# Power BI Dashboard Projects

## Project Overview

This folder contains Power BI reports developed to analyze data and communicate findings through interactive visualizations.

## Tools and Features

* Power BI Desktop
* Power Query
* Data Modelling
* DAX
* Interactive Reports
* Charts and Slicers

## Project Objectives

* Transform data for reporting.
* Develop data models and relationships.
* Create measures and calculations using DAX, where applicable.
* Design interactive reports.
* Present useful information through visualizations.

## Files Included

* `.pbix` files containing Power BI reports.
* PNG screenshots showing dashboard previews.

## How to Use

1. Download the `.pbix` file.
2. Open it in Power BI Desktop.
3. Configure any required data sources.
4. Explore the report pages and interactive filters.

## Skills Demonstrated

Data Transformation, Data Modelling, DAX, Data Visualization, and Business Intelligence.
