# MySQL Assignments

## Project Overview

This folder contains SQL assignments demonstrating database querying, filtering, data retrieval, and analysis using MySQL.

## Topics Covered

* SELECT and DISTINCT
* WHERE conditions
* AND and OR operators
* LIKE, IN, and BETWEEN
* Aggregate functions
* GROUP BY and HAVING
* SQL joins
* Subqueries
* Window functions

## Files Included

SQL scripts containing queries and practice exercises for different database concepts.

## How to Run

1. Install MySQL Server and MySQL Workbench.
2. Open the required `.sql` file in MySQL Workbench.
3. Review the queries.
4. Execute the script against the appropriate database.

## Skills Demonstrated

SQL querying, data filtering, data aggregation, relational database concepts, and data analysis.
