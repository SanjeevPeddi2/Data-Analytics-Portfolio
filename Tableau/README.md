# Tableau Dashboard Projects

## Project Overview

This folder contains Tableau assignments and dashboards created to explore data, identify trends, and present insights visually.

## Tools and Features

* Tableau Desktop
* Interactive Dashboards
* Charts and Graphs
* Filters
* Calculated Fields
* Parameters, where applicable

## Project Objectives

* Explore datasets through visual analysis.
* Create charts and interactive dashboards.
* Use filters to investigate different data segments.
* Present trends and findings in an understandable format.

## Files Included

* `.twb` or `.twbx` Tableau workbooks.
* PNG screenshots of completed dashboards.

## How to Use

1. Download the workbook.
2. Open it using a compatible version of Tableau.
3. Configure any required external data connections.
4. Explore the dashboard and its filters.

## Skills Demonstrated

Data Visualization, Dashboard Development, Data Exploration, and Analytical Thinking.
